# Luxe Canvas

Create a premium, modern, luxury hospitality and restaurant website for my uncle's business. The website should be inspired by the overall premium, cinematic, and high-end visual experience of Bastian Hospitality, but it must have a completely original design, branding, content, layout, animations, and visuals. Do not copy their exact website, logo, text, images, or copyrighted design.

The final website should look like a real professional luxury hospitality brand website that is ready to launch publicly.

AESTHETIC COLOUR PALETTE:
Use a sophisticated luxury colour palette:

Deep Charcoal / Black: #111111 for premium dark backgrounds

Warm Beige: #E8DED0 for elegant sections

Champagne Gold: #C9A96E for buttons, borders, highlights, and important accents

Off White: #F7F4EF for text and clean sections

Dark Brown: #2B211B for subtle premium accents

Use the colours minimally and elegantly. Avoid bright, flashy, or overly saturated colours. Use champagne gold sparingly for CTA buttons, hover effects, borders, icons, and important highlights. Maintain excellent contrast and readability.
